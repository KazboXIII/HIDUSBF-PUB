What the numbers mean

Launch
One start of the app. Starting it three times in a day is three launches.
Active install
An install that started at least once in that period. Each is a random id made once per install, so one person on two PCs counts as two, and a fresh Windows counts as new. It isn’t a count of people.
What the counter misses
Anyone who turned off “Send anonymous usage counts”, and anything older than the counter: public builds count from 4.2.0, experimental builds from exp.32. Nothing before the first counted day exists.
Today
The UTC day still running, so its number is still growing. Charts draw it as an outlined bar.
Installs seen
Every install the counter has ever heard from, active or not.
Auto update
A first start right after an update that installed itself, when that setting is on.
Download
GitHub’s lifetime count for one file. It counts every fetch, including repeats and in-app updates, so it isn’t a count of people. GitHub gives no dates, which is why there’s no downloads-per-day chart.
Installer and checksum
The Setup .exe and its .sha256 file. They’re kept apart because the checksum is only used to check a download, and the app’s updater fetches it too.
Public and experimental
Download counts cover the public repository. Experimental builds live in a private repository this page can’t read, so their downloads aren’t included. Usage does cover both.
